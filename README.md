# RallyStats 🏸

**RallyStats** is a badminton match tracking and performance analytics application designed to help players record their matches, monitor results, and track their progress over time.

The application provides a clean and intuitive interface for managing match history, analyzing performance, and keeping all badminton statistics in one place.

## Features

- **Dashboard** — Overview of match statistics and performance.
- **Match History** — Browse, search, sort, and filter recorded matches.
- **Match Management** — Add, edit, and delete matches.
- **Match Results** — Track wins, losses, and game scores.
- **Player Profiles** — Organize player information and match records.
- **Data Persistence** — Store match data locally using LocalStorage.
